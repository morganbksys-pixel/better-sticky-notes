Les notes modifiées remontent désormais en tête de liste dans **Mes notes**, les groupes et les recherches.

- Le tri utilise la dernière modification du titre, du texte, d’une case à cocher ou des captures, avec repli sur la date de création.
- Ouvrir, déplacer, masquer, épingler ou verrouiller une note ne la fait pas remonter. La sélection multiple est conservée lors du réordonnancement.
- L’ordre est conservé après redémarrage, y compris pour les notes protégées. Les anciennes notes sans date gardent leur ordre jusqu’à leur prochaine modification.

Extraire entièrement `BetterStickyNotes-0.21.5-win-x64.zip`, puis lancer `BetterStickyNotes.exe`.
