Les notes modifiées remontent désormais en tête de liste dans **Mes notes**, les groupes et les recherches. Le tri utilise la dernière modification du titre, du texte, d’une case à cocher ou des captures, avec repli sur la date de création. L’ordre est conservé après redémarrage, y compris pour les notes protégées ; la sélection multiple est conservée lors du réordonnancement.

Ouvrir, déplacer, masquer, épingler ou verrouiller une note ne la fait pas remonter. Les anciennes notes sans date gardent leur ordre jusqu’à leur prochaine modification.

La punaise du post-it utilise une seule silhouette inclinée : contour quand la note est libre, pleine quand elle reste au premier plan. Les deux états gardent la même couleur et un fond transparent.

L’indicateur des notes épinglées dans **Mes notes** reprend cette même punaise pleine. Le comportement d’épinglage est inchangé.

Extraire entièrement `BetterStickyNotes-0.21.6-win-x64.zip`, puis lancer `BetterStickyNotes.exe`.

Les tests de régression sont exécutés par GitHub Actions. Les consignes du dépôt réservent désormais les tests locaux aux demandes explicites.
